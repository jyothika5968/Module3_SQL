**📊 SQL Practice & Concepts Repository**

## 📌 Overview

This repository contains structured SQL scripts covering fundamental to advanced concepts. It is designed as a learning and practice resource for mastering SQL, including real-world query scenarios.

---

## 🎯 Objectives

* Strengthen SQL fundamentals
* Practice real-world data querying
* Understand advanced database concepts
* Prepare for Data Analyst / Developer roles

---

## 🧩 Topics Covered

### 🔹 Basics

* Basic queries
* Data retrieval
* Filtering & sorting

### 🔹 DDL (Data Definition Language)

* CREATE
* ALTER
* DROP

### 🔹 DML (Data Manipulation Language)

* INSERT
* UPDATE
* DELETE

### 🔹 DQL (Data Query Language)

* SELECT statements
* WHERE, GROUP BY, ORDER BY

### 🔹 Joins

* INNER JOIN
* LEFT JOIN
* RIGHT JOIN
* FULL JOIN

### 🔹 Functions

* String functions
* Aggregate functions

### 🔹 Advanced SQL

* Subqueries (Nested Queries)
* Window Functions

### 🔹 Database Programming

* Triggers
* Stored Procedures
